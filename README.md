# 📖 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais do desenvolvimento Front-end, consumindo uma API REST para exibir informações dos Pokémon de forma dinâmica.

A aplicação realiza requisições para a **PokéAPI**, permitindo carregar dados como:

* Nome
* Número da Pokédex
* Tipo
* Imagem
* Lista de Pokémon

Além disso, o projeto reforça conceitos importantes de JavaScript moderno, manipulação do DOM e consumo de APIs utilizando `fetch()`.

# 💻 Como executar o projeto

## Clone o repositório

```bash
git clone https://github.com/PedroRikTi/pokedex-js.git
```

## Entre na pasta

```bash
cd pokedex-js
```

## Abra o projeto

Basta abrir o arquivo **index.html** no navegador.

Ou utilize uma extensão como **Live Server** no Visual Studio Code.
